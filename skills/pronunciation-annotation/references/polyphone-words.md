# 口播高频易错多音字标注库

短视频口播稿多音字（易错音）注音依据。标注时按本库逐字比对，未覆盖的字按《现代汉语词典》标准读音判定。

---

## 标注格式与约定

- **格式**：`[字=pinyin+声调数字]`（字与拼音用等号连接、不加空格），**目标字收进方括号、紧跟其原位置，括号外不重复该字**。词内目标字在中后部：紧贴前字（"地狱变相"→"地狱变[相=xiang4]"、"家什"→"家[什=shi5]"、"睡不着"→"睡不[着=zhao2]"）；目标字在词首：注音置于词首（"几乎"→"[几=ji1]乎"、"觉得"→"[觉=jue2]得"）。示例：`[长=chang2]`、`[重=zhong4]`。
- **声调数字**：1=阴平（ā）、2=阳平（á）、3=上声（ǎ）、4=去声（à）、5=轻声。
- **范围**：只标"容易读错、语境有歧义"的多音字；语气词（的/了/着/地 作助词时）与人人都不会读错的字不标。
- **策略**：同一多音字全文**每次出现都标注**（含同音重复，供 TTS 逐词标音）；同一字以**不同读音**出现时，每处标注对应读音（见 pronunciation-annotation 的"多音字标注"步骤）。
- **固定读音词**：整体注音，标注在该词首个多音字后，如"提[供=gong1]"、"[角=jue2]色"。
- **生僻字**（单音但易读错的人名/地名/书名/器物/雅词）另见 `rare-words.md`，标注格式完全一致。

## 三、语气词 / 高频虚字（默认不标）

以下字人人会读、极少读错，**默认不标注**，除非语境确有歧义：

- 的（de / dí 的确 / dì 目的）：作助词读 de 不标；"的确"中 dí 可标 `[的=di2]`。
- 了（le / liǎo 了解）：作助词读 le 不标；"了解""了不起"中 liǎo 可标 `[了=liao3]`。
- 着（zhe / zháo / zhuó）：作助词读 zhe 不标；"着急""执着"已在上表按语境标。
- 地（dì 土地 / de 助词）：作助词读 de 不标。
- 都（dōu 都 / dū 都市）："都"读 dōu 时不标；"都市""首都"可标 `[都=du1]`。

## 四、判定与输出提醒

1. **先合规、后注音**：违规扫描优先，注音不影响合规判定结果。
2. **只标易错**：口播稿以"照读不读错"为目标，宁可少标不可滥标；人人会读的字标了反而干扰主播视线。
3. **每次出现标注**：同一多音字全文**每次出现都标注**（含同音重复，供 TTS 逐词标音）；同一字换读音再次出现时更须重标（如 几乎[几=ji1]乎 → 几[几=ji3]十年）。
4. **注音不改字**：标注是追加在原文后的注释，绝不改动原文任何文字。
5. **有违规句时**：注音版口播稿基于"合规改写后的全文"生成，确保主播拿到即可照读。
6. **生僻字走 `rare-words.md`**：人名/地名/书名/器物/雅词中的生僻字（单音但易读错）按生僻字库标注，格式与多音字完全一致，两库不重复收录。
