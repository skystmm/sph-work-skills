# 口播稿注音标注器（多音字 + 生僻字 + 年份转汉字）

对一段口播文案（视频号 / 抖音 / 快手等）做多音字与生僻字注音标注（统一格式 `[字=pinyin+声调]`，如 `[长=chang2]`、顾[恺=kai3]之），产出可直接照读的注音版口播稿，并将阿拉伯数字年份转为中文数字，避免主播照读时念错或卡顿。

## 适用场景

- 用户要求"帮我标一下多音字 / 易错音""这段口播哪几个字容易读错"
- 用户要求"帮我标一下生僻字"（人名 / 地名 / 书名 / 器物 / 雅词）
- 用户需要一份"拿到就能照读、不读错字"的注音版口播稿
- 口播稿中出现阿拉伯数字年份（如 1948 年），需要转为中文数字（一九四八年）便于照读

## 工作流程

### 1. 通读全文

将口播稿按句切分通读，识别语境，为后续判定"哪个字容易读错、读哪个音"做准备。

### 2. 多音字标注（易错音注音）

**标注规则**：

- **只标注"容易读错、语境有歧义"的多音字**，不标人人都会读的常用字（如"的 de""了 le""着 zhe"等语气词默认不标，除非语境特殊、确有歧义）。
- 标注格式：`[字=pinyin+声调数字]`（字与拼音用等号连接、不加空格），**目标字收进方括号、紧跟其原位置，括号外不重复该字**。词内目标字在中后部时，注音紧贴前字（如"地狱变相"→"地狱变[相=xiang4]"、"吴带当风"→"吴带[当=dang1]风"、"家什"→"家[什=shi5]"、"睡不着"→"睡不[着=zhao2]"）；目标字在词首时，注音置于词首（如"几乎"→"[几=ji1]乎"、"觉得"→"[觉=jue2]得"）。示例：`[长=chang2]`、`[重=zhong4]`、`[处=chu3]`、`[主角=jue2]`。
- 声调数字约定：**1=阴平（ā）、2=阳平（á）、3=上声（ǎ）、4=去声（à）、5=轻声**。
- 同一多音字在文中**首次出现时标注**，后续**同音**重复出现不再标（保持可读性；用户要求全标除外）；但若同一字以**不同读音**再次出现（如"几乎"[几=ji1]乎 vs "几百年"[几=ji3]百年、"空山"不标 vs "空白"[空=kong4]白、"当时"不标 vs "当成"[当=dang4]成、"一场风波"[场=chang2] vs "官场"不标），**必须在该字另一读音处再次标注**，防止主播按首次读音照读出错。
- 固定读音词整体标注（如"提供 [gong1]"、"角色 [jue2]"），标注在该词首个多音字后。
- 参考 `references/polyphone-words.md` 的口播高频易错多音字库；库中未覆盖的字按《现代汉语词典》标准读音判定。

### 3. 生僻字标注（易错人名 / 地名 / 书名 / 器物 / 雅词）

在标多音字的同时，扫描口播稿中的**生僻字**（单音字但容易读错、或与形近字混淆的人名 / 地名 / 书名 / 器物 / 雅词用字），统一按同格式标注。

**标注规则**：

- **标注格式与多音字完全一致**：`[字=pinyin+声调数字]`，目标字收进方括号、紧跟原位置、括号外不重复该字（如 顾[恺=kai3]之、[亳=bo2]州、女史[箴=zhen1]图、[饕=tao1][餮=tie4]）。声调数字约定相同（1-4 声 + 5 轻声）。
- **只标"容易读错 / 与形近字混淆"的生僻字**；认识且必读对的字不标，宁可少标不可滥标。
- 同一生僻字**首次出现标注**，重复不标（用户要求全标除外）。
- **与多音字库的分工**："多音+生僻"的字（如 期颐的"期[ji1]"、龟兹的"龟[qiu1]"）以多音字库 `polyphone-words.md` 为准，生僻字库不重复收录；纯单音生僻字查 `references/rare-words.md`。
- 参考 `references/rare-words.md` 的口播易错生僻字库（按人名 / 地名 / 书名 / 称谓 / 器物 / 雅词六类组织）；库中未覆盖的按《现代汉语词典》标准读音判定。

### 4. 生成注音版口播稿

将多音字与生僻字标注**混合嵌入**原文：标注不改变任何原文文字，仅以 `[字=pinyinN]` 嵌回原位置，两库互不冲突。若用户同时要求合规检查，先由 `short-video-compliance-judge` 产出合规改写版，再基于改写后的全文插入注音；本 skill 单独使用时基于原文插入注音。

### 5. 年份转汉字优化（口播可读性）

口播稿中若出现阿拉伯数字年份（如「1948 年」「2019 年」），统一改写为中文数字年份，避免主播照读时念得生硬或卡顿，也更贴合视频号口播语感。

**转换规则**：

- 四位年份逐位转中文数字：`1948 年` → `一九四八年`；`2019 年` → `二零一九年`。
- 数字映射：0=零、1=一、2=二、3=三、4=四、5=五、6=六、7=七、8=八、9=九。
- 仅转换「年」前的纯数字年份；不转换页码、序号、价格、数量等非年份数字（如「第 3 章」「9.9 元」保持原样）。
- 世纪 / 年代表述（「80 年代」「19 世纪」）按语境酌情转中文（「八十年代」「十九世纪」），保持全稿语感统一即可。

**应用位置**：在生成「注音版口播稿」时一并套用；若原文全篇为中文年份表述（如「一千多年」「唐代」），此步跳过、无需转换。

### 6. 输出结构

输出结构化结果，顺序如下：

```
## 一、多音字标注表
| 原文字 | 标注读音 | 常见误读 | 语境说明 |

## 二、生僻字标注表
| 原文字 | 标注读音 | 常见误读 | 语境说明 |
（仅当文中有生僻字时输出；无则跳过并注明"全文无生僻字"）

## 三、注音版口播稿
（全文插入 [字=pinyinN] 标注，多音字与生僻字混合嵌入，阿拉伯数字年份已转中文，可直接照读）
```

### 7. 可复制交付（一键复制按钮）

注音版口播稿除代码块外，**必须同时提供一个带「一键复制」按钮的可复制版本**，方便用户直接取用：

- **方式一（优先）**：用交互组件渲染口播稿卡片，卡片内置「一键复制」按钮，点击即复制注音版全文到剪贴板。
- **方式二（备选）**：生成独立 HTML 文件（含复制按钮），经文件展示交付，浏览器打开后点按钮复制。
- **按钮实现要求**：
  - 优先 `navigator.clipboard.writeText(text)`，失败时降级 `document.execCommand('copy')` + 临时 `textarea` 方案；
  - 复制成功后按钮文案短暂变为「已复制」（约 1.8 秒后还原），给出明确反馈；
  - 复制内容 = **注音版口播稿全文**（含 [字=pinyinN] 标注，不含任何说明文字、表头、标题）。
- **数据源一致性**：复制文本必须与「注音版口播稿」代码块内容逐字一致，杜绝双版本不同步。

## 关键注意

- 注音标注（多音字 + 生僻字）**只加注音、不改文字**；若注音稿源自合规改写版，必须先确认触发句已替换再照读。
- 多音字与生僻字共用同一 `[字=pinyinN]` 格式，两库分工明确：多音字查 `polyphone-words.md`，生僻字（人名/地名/书名/器物/雅词）查 `rare-words.md`；"多音+生僻"的字归多音字库，不重复收录。
- 声调数字与拼音字母之间不加空格（`chang2` 而非 `chang 2`）；方括号内字与拼音之间用等号连接、不加空格（`[长=chang2]`）。
- 宁可少标，不可滥标：人人都会读的字、语气词（的/了/着/地 作助词时）一律不标。
- 年份转汉字：仅限「年」前纯数字年份，不波及价格 / 序号 / 数量。
- **不含违规判定**：本 skill 只做照读优化（注音 + 年份转汉字），平台违规判断与合规改写走 `short-video-compliance-judge`。

## 配合使用的 skill

- **short-video-compliance-judge**：判定口播文案是否触发平台违规（诱导互动等七类），产出合规改写版；改写定稿后交给本 skill 注音。
