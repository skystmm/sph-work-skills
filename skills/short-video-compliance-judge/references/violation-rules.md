# 违规规则库与改写范式

短视频平台（视频号 / 抖音 / 快手）"诱导互动及低质互动"类违规的完整判定依据。判定时按以下六类逐句比对。

---

## 类别一：恐吓 / 诅咒

**定义**：以负面后果威胁、诅咒用户或其亲友，制造恐惧以迫使其互动或服从。

**触发关键词 / 句式**：
- "不转发的…会倒霉 / 出事 / 遭报应"
- "不点赞的人…注定平庸 / 一事无成 / 吃亏"
- "不听老人言，吃亏在眼前"（用在强制语境）
- 诅咒类："不转全家…""不看的都…"

**严重程度**：🔴 致命（含明确诅咒/恐吓指令）

**改写方向**：删除威胁，改为正向描述事实或观点。
- ❌ "不点赞的人注定平庸"
- ✅ "这本书让我重新理解了什么叫做活着"

---

## 类别二：道德绑架

**定义**：用道德标准、身份标签、群体认同施压，使用户因"不做就不够好"而互动。

**触发句式 / 关键词**：
- "真正爱读书的人都会点赞"
- "为人父母的都该转发"
- "有良心的都…"
- "转发给需要改变命运的人"
- "但凡孝顺的都…"

**严重程度**：🟡 风险（叠加其他更易判）

**改写方向**：去掉身份标签与"都该"句式，直接输出内容。
- ❌ "真正爱读书的人都会点赞"
- ✅（删除该句，让内容本身引发共鸣）

---

## 类别三：互动换好运 / 运势

**定义**：将互动（点赞、评论、转发）与好运、运势、福报绑定。

**触发句式**：
- "点赞逢考必过"
- "转发今年走大运"
- "评论的人今年脱单"
- "转发的人全家平安"

**严重程度**：🔴 致命

**改写方向**：彻底移除运势绑定，改为中性祝福或直接删去。

---

## 类别四：悬念强迫互动

**定义**：用悬念、压轴、秘密诱导用户看完全程或做出互动，典型为"答案/福利在评论区""最后一条决定命运"。

**触发句式 / 关键词**：
- "想知道答案的评论区见"
- "尤其是最后一条，决定了你的…"
- "最后一条很多人一辈子没想明白"
- "秘密我都放在评论区了"
- "不看到最后你会后悔"

**严重程度**：🟡 风险（纯悬念钩子单独出现可能不判，但配合评论引导必判）

**改写方向**：把"悬念吊着不给"改为"直接讲出来"，降低施压感。
- ❌ "尤其是最后一条，他直接决定了你的晚年是过得委屈还是舒坦"
- ✅ "尤其是最后一条，往往最容易被忽略，也最影响晚年相处质量"

---

## 类别五：承诺诱导（礼品 / 资料 / 教程 / 运气 / 财富）

**定义**：以提供无法即时验证、且常以互动为前置条件的好处，引导用户互动。

**触发句式 / 关键词**：
- "点赞送书单 / 资料包"
- "评论领教程"
- "关注免费领读书笔记"
- "私信'666'发你方法"
- "转发抽书"

**严重程度**：🔴 致命（用利益换取互动）

**改写方向**：移除"互动=获取利益"的条件句。书籍/资料可改为自然橱窗引导（见类别六安全区），不以互动为交换条件。

---

## 类别六：无法验证的承诺

**定义**：做出夸张、无法验证的效果承诺，常见于知识/成长/带货类内容。

**触发句式**：
- "这本书能改变你的命运"
- "读了就能月入过万 / 逆袭人生"
- "照做三个月脱胎换骨"
- "用了这个方法孩子成绩暴涨"

**严重程度**：🟡 风险

**改写方向**：用具体内容替代效果承诺。
- ❌ "这本书能改变你的命运"
- ✅ "这本书讲了一个 89 岁老太太如何与自己和解的真实故事"

---

## 类别七：健康功效绝对化宣称

**定义**：在养生 / 中医 / 情绪健康类内容中，宣称某种做法、情绪、穴位、食材能"治XX病""很多病自然就好""百病不侵"等疾病自愈或医疗功效的绝对化表述。此类内容虽不属于"诱导互动"类，但可能触发平台健康 / 医疗内容审核（功效宣称、疾病自愈暗示），在养生类口播中高频出现，务必排查。

**触发句式**：
- "心平能御三千疾，很多病自然就好"
- "这样做百病不侵"
- "坚持XX，高血压糖尿病都能好"
- "这个穴位包治失眠"

**严重程度**：🟡 风险（健康审核向，非诱导互动向；叠加"去医院都没用"等贬医表述会升级为 🔴）

**改写方向**：加缓冲词弱化绝对化，改为"传统说法 / 养生观点 / 有助于缓解"：
- ❌ "心平能御三千疾，心理平静了，很多病自然就好"
- ✅ "老话说心平气和，情绪稳了，人自然舒服些，很多小毛病也能少找上门"

---

## 安全区（🟢 保留，勿过度修改）

以下内容不违规，判定时标 🟢 并建议保留原样：

- **纯观点输出**：如家庭关系、为人处世的经验总结。
- **故事叙述 / 情感共鸣**：用真实故事、人物经历引发共鸣。
- **自然橱窗 / 书籍引导**："感兴趣的话可以翻翻左下角这本《…》""这本书在橱窗" —— 不绑定互动、不承诺效果，合规。
- **正常结尾升华**：以观点收束，不指令互动。

---

## 通用改写规则（10 条红线对照）

| 千万别写 | 可以写 |
|---------|--------|
| 评论区留下… | 把观点讲透，让观众自己想说 |
| 点赞的都… | 直接输出价值 |
| 关注我告诉你… | 把答案直接讲出来 |
| 转发给需要的人 | 不提转发，靠内容自传播 |
| 想看的扣 1 | 用"感兴趣可以看橱窗"自然带过 |
| 不转发的都… | 删去威胁，改正向描述 |
| 真正…的人都会… | 去掉身份标签与"都该"句式 |
| 读了就能逆袭 | 用具体故事/内容替代效果承诺 |
| 尤其是最后一条决定命运 | 降施压，改为"最易被忽略的一条" |
| 点赞送资料 | 移除互动换利益的条件句 |

## 账号处理决策树

```
收到预警 / 自行检查
├─ 仅预警，播放量正常
│   └─ 编辑重发：去掉触发句后重新发布，不必删
├─ 已限流（个位数 / 远低于均值）
│   └─ 删除 → 用合规版本重发一条
└─ 正式处罚通知（限流 N 天）
    └─ 删除 → 申诉（视频号助手→创作中心→违规记录→申诉）→ 后续规避
```

**多次预警影响**：单条预警影响不大；连续 3 次以上可能进限流池，恢复周期 1–4 周。务必改后规避再触发。
