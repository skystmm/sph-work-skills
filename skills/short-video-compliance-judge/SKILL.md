# 短视频文案合规判定器

判定一段口播文案（视频号 / 抖音 / 快手等）是否踩中平台"诱导互动及低质互动"类违规规则，定位具体触发句、标注严重程度、给出合规改写与账号处理建议。

## 适用场景

- 用户发来一段口播文案，问"这条会不会被判违规 / 被限流？"
- 用户收到平台违规预警（如"作品可能涉及恐吓、道德绑架、悬念强迫互动、承诺诱导"），想排查是哪句触发
- 用户要求"帮我检查文案有没有诱导互动""改到合规"

## 工作流程

### 1. 通读并切句

将用户提供的文案按句号、问号、感叹号、换行切分为"句子单元"，逐句扫描。保留原文顺序，便于回指。

### 2. 七类违规扫描

按 `references/violation-rules.md` 中的七类规则逐句比对：

1. 恐吓 / 诅咒
2. 道德绑架
3. 互动换好运 / 运势
4. 悬念强迫互动
5. 承诺诱导（礼品 / 资料 / 教程 / 运气 / 财富）
6. 无法验证的承诺
7. 健康功效绝对化宣称（养生 / 中医类"治XX病""病自然就好"表述，触发健康审核）

每命中一句，记录：原文片段、命中类别、严重程度（🔴 致命 / 🟡 风险 / 🟢 安全）、判定理由。

### 3. 标注严重程度

- 🔴 **致命**：含明确"评论区留下 / 点赞 / 关注我 + 动作指令"等诱导互动关键词，或诅咒/恐吓句式。几乎必判。
- 🟡 **风险**：悬念压迫（"最后一条决定命运"）、道德绑架（"真正爱读书的人都会…"）、无法验证的承诺（"读了就能逆袭"）、健康功效绝对化（"很多病自然就好"）。单独出现可能不判，但叠加易被定性。
- 🟢 **安全**：纯观点输出、故事叙述、自然橱窗引导（"感兴趣可以看左下角这本书"）。保留原样。

### 4. 给出合规改写

对每一处 🔴 / 🟡 触发句，提供改写方案：保留原意与情绪价值，去掉诱导动作或施压感。改写原则见 `references/violation-rules.md` 的"通用改写规则"。

### 5. 处理建议（删 / 改 / 重发）

按用户描述的状态给建议：

- **仅预警、尚未限流**：优先"编辑重发"——去掉触发句后重新发布，不必删。
- **已限流（播放量异常低 / 个位数）**：建议**删除**，用合规版本重新发一条；被限流的视频留存会拖累账号权重。
- **已收到正式处罚通知（限流 N 天）**：删除该视频 → 路径申诉（视频号助手 → 创作中心 → 违规记录 → 申诉）→ 后续严格规避。

### 6. 输出结构

输出一份结构化报告，顺序如下：

```
## 一、判定结论
总体风险：🔴 高危 / 🟡 中风险 / 🟢 基本合规
触发点数量：致命 X / 风险 Y

## 二、逐句定位
| 原文片段 | 类别 | 严重程度 | 理由 |
|----------|------|----------|------|
| … | 诱导互动 | 🔴 | "评论区留下"为明确评论指令 |

## 三、合规改写
（对每处触发句给出改写前后对照）

## 四、处理建议
（删 / 改 / 重发 + 后续创作红线清单）
```

## 关键注意

- 视频号（微信）对"诱导互动"零容忍，**"评论区留下/打出/扣1、点赞的都、关注我告诉你、转发给需要的人"** 是高频必判句式，出现即标 🔴。
- 自然橱窗 / 书籍引导（"感兴趣可以翻翻左下角这本…"）不算诱导，属 🟢，保留。
- 纯观点、故事、情感共鸣内容安全，不要过度修改导致失去原文感染力。
- 改写时优先"降施压感 + 去掉指令"，而非整段删除，保住完播率与转化意图。
- **注音标注与年份转汉字不在本 skill 职责内**：若用户需要可照读的注音版口播稿（多音字/生僻字标注、阿拉伯数字年份转中文），切换到 `pronunciation-annotation` skill 处理；合规改写后的定稿文本可直接交给该 skill 做照读优化。

## 配合使用的 skill

- **pronunciation-annotation**：对合规改写后的口播稿做多音字 / 生僻字注音标注，产出注音版口播稿，并将阿拉伯数字年份转为中文数字（如 1948 年 → 一九四八年）。
