# 短视频字幕排版

## Overview

将任意长度的视频口播文案按语义与口语节奏拆分为快速易读的短句字幕，每行严格不超过 8 个汉字，输出无标点纯文本，可直接导入剪映 / PR / 必剪等剪辑软件字幕轨道。

## 初始化回复

用户发送文案后，先回复固定话术（不要做其他多余动作）：

> 明白，纯净版字幕分行功能已加载。请发送您的文案，我将严格执行每行≤8字、无标点、一句一行的排版规则。

## 核心约束（必须 100% 遵守）

1. **每行字数**：每行汉字严格不超过 8 个字（数字、英文单词按 1 个字符计）。遇到长句必须在自然的语义或配音停顿处拆分。
2. **禁止拆分词组**：不得在完整词语中间断行。常见不可拆分词组包括但不限于：中华人民共和国、互联网、社会主义、世界观、人生观、价值观、生活方式、短视频、视频号、直播间、出版社、畅销书、读后感、文学奖、诺贝尔、主人公、这本书、一句话、一辈子、等等。
3. **"的"字不顶行**：任何以"的"开头的行均属违规。遇到"……的+名词"结构时，将"的"字所在意群整体上移或整体下移，保证"的"字位于行中或行尾。
4. **一句一行**：每条字幕独立成行，严禁将多个分句或完整句子合并到同一行。保留原叙事顺序，不得调换或重组。
5. **纯净文本**：输出不得包含任何标点符号（逗号、句号、问号、叹号、引号、省略号、冒号、分号、破折号等）。只允许汉字、数字和极少数的必要英文/符号（如 %、·——用于外国人名音译如 爱丽丝·门罗）。

## 处理流程

### 第一步：拆分

按口语停顿和意群，将文案切分为单行 ≤8 字的短句，保持语义连贯。

- 每个分句 / 完整句子单独成行，不合并。
- 长句在自然停顿处（原逗号位置、意群边界、换气点）断开。
- 断点优先落在完整词组边界，宁可在词组前的介词/连词处断，也不拆词组。
- 以"动词+宾语"结构为单位切分，如"推荐一本""改变了""我的生活"各自成行。

### 第二步：清洗

- 删除所有标点符号。
- 逐行核对字数是否 ≤8。
- 检查词组是否完整、有无在词组中间断行。
- 检查是否有行以"的"开头，如有则把"的"字意群上移或下移。

### 第三步：终检

- 逐行核对字数，确认无一遗漏或超限。
- 运行 `scripts/check_subtitles.py` 做程序化校验（每行 ≤8 字、无标点、"的"不顶行、无空行、常见词组跨行）。
- 任一校验项失败则修正后重新输出，直到全部通过。

## 输出格式

所有结果必须使用代码块（```）包裹，内部仅包含处理后的纯文本字幕，每行一句，行间无空行。代码块外可附带一句极简说明（如需）。

## 示例

### 示例一（普通口播句）

输入：今天给大家推荐一本特别好看的书，这本书改变了我的生活。

输出：

```
今天给大家
推荐一本
特别好看的书
这本书
改变了
我的生活
```

### 示例二（含数字与长句）

输入：这本书在二零二四年卖了超过一百万册，很多读者都说看完舍不得合上。

输出：

```
这本书
二零二四年
卖了超过
一百万册
很多读者
都说看完
舍不得
合上
```

### 示例三（含"的"字结构）

输入：这是一本让人读完心里久久不能平静的书。

输出：

```
这是一本
让人读完
心里久久
不能平静
的书
```

## 校验脚本

使用 `scripts/check_subtitles.py` 对输出的字幕块做程序化终检：

```bash
python3 scripts/check_subtitles.py 字幕文件.txt
# 或从 stdin 读入：
cat 字幕.txt | python3 scripts/check_subtitles.py
```

脚本输出 `PASS` 表示全部行符合规则；输出 `FAIL` 时列出每个违规行及原因（超长 / 含标点 / "的"顶行 / 空行 / 疑似拆分词组），修正后必须重跑直至 PASS。

注意：脚本仅做启发式词组检测（内置常见词表），精确的词组完整性仍依赖排版时的语义判断，两者结合使用。
