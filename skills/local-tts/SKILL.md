# 本地中文语音生成

此技能需要本机 TTS 后端、Python 环境、CosyVoice3 上游源码与模型；模型、录音和输出不随技能发布。首次使用请先阅读同目录 `install-guide.md`，检查项目是否准备完成。不要下载模型或安装依赖，除非用户同意。通过 `VOICE_TTS_ROOT` 或已安装技能所在目录找到后端，使用该目录 `.venv/bin/python` 和 `scripts/tts_cli.py` 的绝对路径；若路径或依赖不可用，向用户报告，不猜测或静默换模型。CLI 会切换工作目录，文件输入与用户指定输出必须使用绝对路径。容器和远程客户端需要实际能访问运行环境及输出文件。

## 音色和交互

用户可先提供文字、先选音色，或同时提供。调用 `voices list` 查询音色；单次选择不修改默认音色。未指定时用已配置默认音色；没有默认音色时列出可选项并询问，不要猜测。用户明确要求修改默认时使用 `voices default 音色ID`。

创建声音时，要求本人或已获授权的参考音频和与录音逐字一致的文本，在确认授权后使用 `voices add --id ID --name 名称 --audio 绝对路径 --prompt-text 逐字文本 --authorized`。注册仅保存资料，需试听验收；不要覆盖或删除已有音色。

## 合成

先用 `models` 检查模型能力；用户未选择模型时使用配置的模型。使用 `parse --text 文字` 或 `parse --file 绝对路径` 预览标注，再用 `synth --text 文字` 或 `synth --file 绝对路径` 生成，按需传入 `--voice`、`--model`、`--speed`、`--output`；也可用 `--stdin`。长文必须完整保留，优先文件或标准输入，勿将未转义文字拼接为 shell 命令。

支持 `[重=zhong4]`、`[break 500]`、`<emphasis>词</emphasis>` 等项目定义的标注子集，并非完整 SSML；只按用户要求添加标注。不得静默忽略不支持的标注或切换声音。不把 mock 合成当作真实语音。成功后报告 CLI JSON 返回的音频路径、音色、模型及时长；声音相似度和发音需用户试听。
