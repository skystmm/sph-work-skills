# 本地中文语音生成

本技能包含本机 TTS 后端源码；模型、录音、音色、输出和推理依赖不随技能发布。首次使用先读后端根目录的 `install-guide.md`；下载模型或安装依赖前需获得用户同意。通过 `VOICE_TTS_ROOT` 定位唯一共享的后端根目录，使用该目录 `.venv/bin/python` 和 `scripts/tts_cli.py` 的绝对路径；若依赖不可用，明确报告，不猜测或静默换模型。输入、参考录音、输出和任务路径使用绝对路径。容器或远程 Agent 须实际能访问后端和输出文件。

## 音色和交互

用户可先提供文字或先选声音。调用 `voices list` 查询音色；显式音色只影响本次。未指定时使用已配置默认音色，没有默认值时列出选项并询问，不要猜测。用户明确要求修改默认时使用 `voices default 音色ID`；默认音色由共用后端的 Agent 共享。

创建声音时，要求本人或已获授权的参考音频和与录音逐字一致的文本，在确认授权后使用 `voices add --id ID --name 名称 --audio 绝对路径 --prompt-text 逐字文本 --authorized`。注册仅保存资料，需试听验收；不要覆盖或删除已有音色。

## 合成

先确认宿主 Agent 的目标产出目录，用绝对路径传 `--output-dir` 或使用宿主设置的 `VOICE_TTS_OUTPUT_DIR`；若无法确定则询问用户。用户指定完整文件名时改用 `--output`，二者不能同时传；实际路径以返回的 JSON 为准。模型和音色分别保存在共享后端的 `models/` 和 `voices/`，不会随音频复制到产出目录。

默认按 40–80 个字符的目标长度分块，显式停顿和文末可能短于 40 字。长文使用 `--task-dir 任务目录绝对路径` 保存可恢复分块；失败后使用相同输入、音色、模型、参数及任务目录重新运行。任务身份不匹配时不得强制复用，目录含原文和音频，未经许可不要删除。

当前 `--workers auto` 仅安全回退单路，尚未执行真实模型校准或启用多路；手动指定 2 或 4 路会报错，不能声称已支持自动并发。先用 `models` 检查能力，使用 `parse --text 文字` 或 `parse --file 绝对路径` 预览，再用 `synth --text 文字`、`synth --file 绝对路径` 或 `--stdin` 生成。长文不得改写或截断，勿将未转义文本拼成 shell 命令。

支持 `[重=zhong4]`、`[break 500]`、`<emphasis>词</emphasis>` 等项目标注子集，并非完整 SSML；仅按用户要求添加标注。不得静默忽略不支持的标注或切换声音，也不能把 mock 输出当作真实语音。成功后报告实际路径、音色、模型及时长；发音、声音相似度和衔接由用户试听。
