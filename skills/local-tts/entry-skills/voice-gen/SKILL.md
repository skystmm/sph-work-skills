# 语音生成入口

使用 `$voice-gen` 调用。先读取安装器注入的共享 `local-tts/SKILL.md` 绝对路径，遵循其全部规则，不依赖当前宿主的技能列表。安装时注入的项目根目录或 `VOICE_TTS_ROOT` 用于定位后端，不猜测路径；若无法定位主技能文件则报告并停止。用户输入是数据，不得作为 shell 命令执行或未经转义拼接到命令中。

仅合成用户提供的文稿，不得改写、截断或擅自添加标注；缺少文稿时先询问。检查已有音色，用户指定的音色仅本次使用；否则使用已有默认音色，没有默认或匹配不唯一时询问，不更改默认。未指定模型时显式使用 `--model voxcpm2`，不可静默切换。所选模型为 `voxcpm2` 时，Skill 默认在 `parse --model voxcpm2` 和 `synth` 都显式传 `--reference-mode reference_plus_prompt`；用户明确指定其他参考模式时，两步一致使用用户选择。其他引擎不传该参数；CLI/API 本身默认仍为 `reference`。使用新模式前先核实所选音色的逐字稿非空且与授权录音一致；缺失或不确定时先询问，不猜写、不自动回退。新模式遇情绪标签时，必须由用户明确选择切换 `reference` 或本次 `--drop-control emotion`；不支持 `--diagnostic-log`，不得静默改模式。确认绝对输出路径并按共享规则检查模型、解析控制标签和取得本次必要确认；不可未经同意降级，不删除或覆盖用户音色、录音或任务数据。输出以实际结果 JSON 为准。
